## 📂 TECHNICAL DEEP DIVE (Sous le capot)

Pour les développeurs et Growth Hackers, voici comment ce moteur tourne :

### 🛠 Stack & UX Psychology
* **Neuro-Design (Glassmorphism)** : Utilisation de flous d'arrière-plan et d'effets de profondeur (3D Tilt) pour augmenter la valeur perçue du contenu.
* **PWA Ready (Progressive Web App)** : Le fichier `manifest.json` permet d'installer ce savoir directement sur l'écran d'accueil, réduisant la friction d'accès à zéro.
* **Algorithme de "Featured Resource"** : Un script JS fait tourner la ressource mise en avant toutes les 3 heures pour créer un sentiment de nouveauté (Dopamine Loop) et encourager les visites récurrentes.
* **Internationalization (i18n)** : Système de bascule FR/EN instantané pour toucher une audience globale sans rechargement.
